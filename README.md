## GIT Instructions

**Ctrl + Shift + P** and type GitHub: Sign in and complete the log in

``` 
git --version
git init
git clone https://github.com/Bryan-tec/practices-technologies.git
git config --global user.name "YOUR_USERNAME"
git config --global user.email "TU_EMAIL_DE_GITHUB"
```
For more security and for an easy connection try to use a ssh connection:
```
git --version
git init
ssh-keygen
git config --global user.name "YOUR_USERNAME"
git config --global user.email "TU_EMAIL_DE_GITHUB"
```
